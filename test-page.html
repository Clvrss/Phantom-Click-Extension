Phantom Click — Link Test Page

Test links for the Phantom Click extension (v1.4). Every “Expected” line below was calculated with the extension’s own rules and the default lists in lists/, so it should match what you see. Hover a badge to open its card and compare the rules, score and notes.

How to read the results
  • Score is the sum of the matched rules (R-01 25, R-02 25, R-03 30, R-04 50, R-05 55, R-06 60, R-07 60), capped at 100. A High rule (R-04 to R-07) raises the score to at least 51. Safe 0–20, Warning 21–50, Risky 51–100.
  • .example links: this ending is reserved and never resolves, so the extension always adds R-02 (+25), and after the check the card also says “Couldn't check this link. Be careful.” A failed check never lowers the score: it is at least 25.
  • Internet needed for links to real sites (example.com, google.com and so on). Offline, they become Warning (couldn't check).
  • Serve this page over http (python -m http.server 8000, then open http://localhost:8000/test-page.html). Opened as a file, Chrome needs “Allow access to file URLs” for the extension.
  • Test clicks never navigate away. Reload the extension and refresh the page after editing lists/known-safe.txt or lists/known-phishing.txt.

Check your own link

Type or paste a domain or a full address. It is added below as a real link, so Phantom Click puts a badge on it. Use .example names to avoid contacting real sites. Use javascript:void(0) or data:… to test unsupported schemes.

    8. Redirect resolution

    These need internet access. A network error or timeout shows Warning (at least 25), never Safe. A server that answers with an error status still counts as checked and adds a note.

    Network test

    Redirect to example.com

    Rules: R-05 · Score: 55 · Badge: Risky

    10. Two-page card and detailed analysis (URLvet)

    1. Open the Phantom Click toolbar menu and check that Detailed analysis (URLvet) is on. It uses URLvet's public server automatically; there is nothing to set up (it needs internet).
    2. Hover a badge below: page 1 appears at once and nothing is sent to URLvet.
    3. Click the badge (or press More Detail analysis): page 2 opens with a loading indicator, then URLvet's verdict, redirect chain and explanations. The badge itself does not change.
    4. Previous Page (or clicking the badge again) returns to page 1. Esc or a click elsewhere closes the card.
    5. Turn the Detailed analysis (URLvet) switch off and open page 2 again: it says the analysis is turned off and nothing is sent. If URLvet cannot be reached (offline, or the public limit of about 20 requests a minute), the card says Detailed analysis unavailable. and offers Try again.
